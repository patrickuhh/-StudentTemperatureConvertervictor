# Student Temperature Converter

A small Java 21 and Maven project for the DevOps homework assignment.

- Converts Celsius to Fahrenheit.
- Converts Fahrenheit to Celsius.
- Includes four JUnit 5 tests.

## Requirements
- JDK 21
- Maven
- Git

## Run tests
```bash
mvn clean test
```

## Run the application
```bash
mvn -q package
java -cp target/classes com.student.temperature.TemperatureApp
```
